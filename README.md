## Repository Structure

The bulk of our code and manuscript is contained within the `manuscript_with_multilevel_metanalysis` alongside detailed descriptions of each step.
Additionally, the folders contain the following:

-  `/Data/` All raw input files with extracted studies.
  
- `/Scripts/` Additional code used for cleaning the raw data before the analyses in the main qmd file.

- `/Output/` Plots and processed datasets generated by code within the main qmd file.

- `/Related_Docs/` Other project-related documents e.g. presentation materials, PRISMA chart.

- `/Render_files/` Files necessary to render the manuscript including references and style templates.

### Loading in the extracted data

To cut on processing time, the simulated datasets and summary outputs for each model are saved as R objects that can be loaded to run our analyses. For that reason, we have commented out the code that generates the simulations and metaregressions in the qmd file. Users uncomment this code (using CTRL+SHIFT+C) if they wish to access the full model outputs and generate the simulated datasets themselves.

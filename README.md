Stringaris, Burman, Delpech, Uher, Bhudia, Miliou, Rokas, Kyriakopoulos, Foulkes, Moreno, Cortese, Lewis & Krebs (2025)

## Repository Structure

The bulk of our code and manuscript is contained within the `manuscript_with_multilevel_metanalysis.qmd`, alongside detailed comments documenting each step.

Additionally, the folders contain the following:

- `/Data/` All raw input files with extracted studies.
  
- `/Scripts/` Additional code used for cleaning the raw data before the analyses in the main qmd file.

- `/Output/` Plots and processed datasets generated by code within the main qmd file.

- `/Related_Docs/` Other project-related documents e.g. presentation materials, PRISMA chart.

- `/Render_files/` Files necessary to render the manuscript including references and style templates.

## Data Extraction & Cleaning

Extracted data from included studies are contained in the `Data/RCT_data/` folder. There are separate spreadsheets for studies pulled from Cipriani et al, Cuijpers et al, Zhou et al, and our own systematic search.

`Data/df_appl_v_orange.xlsx` is the final raw dataset created after cleaning and combining medication and psychotherapy extracted data.

`Data/RCT_data/Trial_design` contains extracted trial characteristics (e.g. number of sites, number of sessions) used in meta-analyses.

`Data/Response_rates` contains our own calculated response rates and those reported by Cuijpers et al. In the final manuscript, we used standardised mean differences (SMDs) as a measure of change in trials.

`Data/Missing_values` contains excel spreadsheets where we documented trials with missing data and our approach to handling these.

## Main Analyses

### Loading in saved data

To cut processing time and power, the simulated datasets and summary outputs for each model are saved as R objects that can be loaded to run our analyses. For that reason, we have commented out the code that generates the simulations and metaregressions in the qmd file. Users can uncomment this code (using CTRL+SHIFT+C) if they wish to access the full model outputs and generate the simulated datasets themselves.

Simulated datasets used when running models are contained in `Data/Simulated_datasets/`. Model summary outputs used to produce tables and plots are found in `Output/R_objects/` and will be loaded automatically by the script in the main quarto.

Note: As the R object is too large to be saved on GitHub, full model outputs (metaregression results from each simulated dataset) will have to be generated by the user to be able to produce Figure S9 in the Supplement - for now, it is commented out.

### Figures

All plots produced within the quarto when running the metaregression models are saved in `Output/Metaregression`.

'Output/Forest/` contains old forest plots which were not included in the paper.
